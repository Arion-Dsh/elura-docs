# 概念

概念页说明 Elura 的组件如何协作，以及这些边界为什么存在。当你需要选择
架构或理解运行时行为时阅读它们；具体实现步骤请查看[指南](/zh/guides/)。

## 从这里开始

- [架构](./architecture)说明 Gateway、World、应用与基础设施的边界。
- [实时游戏开发](../guides/realtime-gameplay)说明模拟、AOI、状态同步、预测、插值与
  倒带如何组合。
- [会话与路由](./sessions-and-routing)介绍认证、重连、所有权、路由与 Push 投递。
- [ELR2 协议](./protocol)说明帧格式、消息类型、保留路由、验证与兼容性。

无论使用本地单体、拆分进程还是分布式部署，这套心智模型都保持不变；
变化的只是基础设施实现。
